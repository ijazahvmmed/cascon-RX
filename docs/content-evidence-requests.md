## Requests for each of the five project profiles
1. A client-approved brief: original problem, constraints, target audience, catalogue size and the initial state of the store.
2. A precise responsibility list: Cascon versus client versus other providers. Separate theme setup from custom development, and generated images from retouched or supplied assets.
3. Deliverable inventory and dates, supported by tickets, approved designs, handover notes or releases.
4. Technical decisions and tradeoffs: theme selection, sections built, integration choices, URL migration or image production controls. Explain why these choices were made.
5. Original before/after screenshots with capture dates, page URLs and permission to publish. Do not use a current brand image as a historical screenshot.
6. If results are to be published: analytics exports, event definitions, time windows, traffic/campaign changes and an agreed attribution method. No conversion, revenue, ROAS, ranking or speed uplift is currently claimed.
7. Written permission for client quotes, named individuals, non-public documents and detailed results. Supply an actual quote and approved attribution; do not draft a testimonial as though a client said it.
