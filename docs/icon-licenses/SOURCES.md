# Icon sources

Interface icons: https://github.com/lucide-icons/lucide (ISC license). Rendered at a consistent 1.5px stroke.
Brand marks: https://github.com/simple-icons/simple-icons (CC0); Shopify and WhatsApp silhouettes retain their original path data. Brand ownership remains with the respective companies.

The AI chooser uses locally hosted OpenAI, Claude, Gemini, Grok and Perplexity marks. Gemini and Perplexity use Simple Icons; Grok uses @lobehub/icons-static-svg 1.102.0 (MIT). Exact sources are recorded in ../brand-assets.json.
